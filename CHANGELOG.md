# Changelog

## 1.0.0 — 2026-08-24

- Initial open-source release extracted from the converter implemented for DCApps.
- Added generic binary and HTML-disguised XLS conversion.
- Added CLI, Tkinter GUI, synthetic tests, resource limits, offline enforcement, atomic output, and overwrite protection.
- Upgraded binary XLS parsing to `xlrd` 2.0.2 or newer.
